# Survive Your Ideas!

A 3D last-one-standing party game. Every few seconds someone is picked to type a disaster, and whatever they type comes to life.

**Play:** open `index.html` from this site. Add `#agent` to the address for AI-agent mode (easy difficulty, clear view, on-screen buttons, and the `window.__game.agent` API).

Everything (Three.js r128, fonts) is bundled into the single `index.html`, so it needs no other files.
